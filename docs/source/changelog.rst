v0.2.0 (2026-10-31)
-------------------

Packaging
~~~~~~~~~

- Publish wheels for `PyEmscripten <https://pyodide.org/en/latest/development/abi.html>`__ (Pyodide 314, ``pyemscripten_2026_0`` platform) (PR :pr:`2`).
- Lower the minimum supported Rust version (MSRV) to 1.93 (PR :pr:`2`).
- Publish wheels for Linux i686, armv7, ppc64le and riscv64 (manylinux and musllinux), and s390x (manylinux only) (PR :pr:`4`).
- Publish wheels for PyPy 3.11 (PyPy 8.0, ``pp80`` ABI) (PR :pr:`1`).
- Publish wheels for GraalPy 3.12 and 3.13 (GraalPy 25) (PR :pr:`3`).
